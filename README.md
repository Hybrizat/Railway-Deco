# Rail Deco（铁路装饰）

一个为原版 Minecraft（NeoForge 1.21.1）制作的铁路装饰方块模组。
**不依赖 Create、MTR 等模组，纯原版可用。**

## 方块

| 方块 | 说明 |
| --- | --- |
| 闸机（Ticket Gate） | JR 风格闸机，纯装饰，保持通行开启造型；中间通道可步行穿过。 |
| 踏切遮断机（Crossing Gate） | 红石驱动的踏切断面：通电时遮断杆落下、警灯交替闪烁、警铃响起；断电后缓慢抬起。 |
| 站台边缘（Platform Edge） | 低矮的黄色盲道/边界条，用于铺设站台边缘。 |

## 踏切遮断机使用说明

- 摆放：遮断杆会朝向玩家放置时面对的方向（面向路中央摆放即可）。
- 杆长：**手持任意物品右键**已放置的遮断机，可在 1~8 格之间循环切换遮断杆长度（默认 2 格）。
- 红石：对遮断机输入红石信号（红石粉、拉杆、红石比较器等均可），通电时遮断杆在约 4 秒内落下，警灯以 0.7 秒节奏交替闪烁并响起警铃；断电后约 6 秒缓慢抬起。
- 一条踏切通常需要两根遮断机：分别放在道路两侧、彼此相对，将同一路红石接到两根上即可。

## 动画参数（参考大宫铁道踏切 Addon「OCR 2.1.10」）

| 参数 | 值 |
| --- | --- |
| 落下用时 | 4.0 秒（80 tick） |
| 抬起用时 | 6.1 秒（122 tick） |
| 警灯闪烁周期 | 0.7 秒（14 tick 交替） |
| 遮断杆角度 | 0° ~ 85° |
| 配重摆动 | 随杆反向小幅摆动（20%） |

## 开发环境

- Minecraft 1.21.1 + NeoForge 21.1.206
- ModDevGradle 2.0.28-beta + Gradle 8.12
- JDK 21（Mojang 官方映射）

## 构建

```bash
./gradlew build
```

产物位于 `build/libs/rail_deco-1.0.0.jar`，放入 `mods/` 文件夹即可。

```bash
./gradlew runClient   # 启动客户端调试
```
